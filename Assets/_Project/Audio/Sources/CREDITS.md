# Звуки мастерской

Используются записи из интернета. У выбранных материалов лицензия CC0 1.0.
Клипы переведены в mono PCM 44.1 kHz, подрезаны по краям, выровнены по пику и получили короткие плавные края.
Громкость событий задаётся в коде, общая громкость берётся из настроек игры.

## Источники

- Kenney, Interface Sounds: https://kenney.nl/assets/interface-sounds
  Архив автора: https://opengameart.org/sites/default/files/kenney_interfaceSounds.zip
- Kenney, Sci-Fi Sounds: https://kenney.nl/assets/sci-fi-sounds
  Архив автора: https://opengameart.org/sites/default/files/sci-fi_sounds.zip
- Kenney, 85 short music jingles: https://kenney.nl/assets/music-jingles
  Архив автора: https://opengameart.org/sites/default/files/jingleSounds_Kenney.zip
- xUMR, frying.loop.ogg: https://freesound.org/people/xUMR/sounds/478655/
  CC0: https://creativecommons.org/publicdomain/zero/1.0/
  Источник шипения припоя. Использована опубликованная автором MP3 preview-запись, переведена в WAV.
